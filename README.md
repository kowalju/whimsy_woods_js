# whimsy_woods_js

<i>**Whimsy Woods**</i> is a simple point-and-click adventure set in a small magical forest, built using **HTML**, **CSS**, and **JavaScript**.<br> The game features basic dialogue boxes, a simple task indicator, and support for saving the current game state.<br> Players can also submit feedback through a built-in form.

All graphics used in the game were created entirely by me.

This project was originally hosted on my another GitHub account and has been transferred to this repository.
